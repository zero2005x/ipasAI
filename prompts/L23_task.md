## 2. P0 — 事實與模擬題錯誤

| 題號／位置 | 改法 |
|---|---|
| `SIM-L23304-002` | 題幹加註「**不含最終 refit**」（GridSearchCV 預設 `refit=True`，實際訓練 121 次不是 120 次） |
| p.75 範例 | 同上，91 次不是 90 次 |
| `SIM-L23101-004` | 說 `ddof=0` 與 `ddof=1`「**必然不同**」→ 資料全部相同時兩者都是 0 |
| `SIM-L23304-00x`（含巢狀 CV 者） | 檢查是否把巢狀 CV 寫成「唯一嚴謹作法」 |

**新增模擬題**（各 1 題）：**NMF 逐元素非負**、**邏輯斯迴歸的對數勝算線性關係**。

### 勘誤表 4 條內容修正（本冊佔 3 條）

| 編號 | 主題 | 改法 |
|---|---|---|
| ERR-17 | NMF | 「非負」是**逐元素非負**（element-wise non-negative），不是矩陣整體為非負純量 |
| ERR-18 | 邏輯斯迴歸 | 假設是「**對數勝算（log-odds）的線性關係**」，不是「線性可分性」 |
| ERR-19 | 召回率 | `Recall = TP/(TP+FN)`。v0.2.0 的 `TP/(TP+FP)` 是**精確率**，必須改 |
| ERR-03 | IDF | 以 10 為底時 `log(100) = 2`（不是 ≈2） |
