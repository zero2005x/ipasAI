### 2.1 核心概念與技術原理

<!-- pdf-page 23 -->
#### 2.1.1 內積與餘弦相似度
核心必考
cos θ = (a · b) ÷ (‖a‖ × ‖b‖)
餘弦相似度為何是文本檢索的預設度量
餘弦相似度只看方向不看長度。兩份內容主題相同但長短懸殊的文件，其向量方向相近但長度差距
大——用歐氏距離會判定為不相似，用餘弦相似度則能正確判定為相似。
值域為 [−1,1]：1代表方向完全相同、0代表正交（無關）、−1代表方向相反。
補充：若向量已正規化為單位長度，餘弦相似度與歐氏距離具單調對應關係，兩者的排序結果相同。

<!-- pdf-page 24 -->
#### 2.1.2 矩陣乘法與維度相容
核心必考
神經網路的一層即為 y =σ(Wx+ b)。維度必須匹配：W為 m×n、x為 n×1、輸出為 m×1。
規則：(m×n)·(n×p) = (m×p)——內側維度必須相同，外側維度成為結果形狀。

<!-- pdf-page 24 -->
#### 2.1.3 特徵值、特徵向量與 SVD
核心必考
Av =λv
特徵向量是「矩陣作用下方向不變、僅被縮放」的方向；特徵值 λ就是縮放倍率。
PCA即對共變異數矩陣做特徵分解——特徵值大小即該主成分所解釋的變異量。
奇異值分解（SVD）：A =UΣV⊤，任意矩陣皆可分解。應用於降維、推薦系統的潛在因子模型與低
秩近似。

<!-- pdf-page 24 -->
#### 2.1.4 PCA五步驟
核心必考
1.中心化（必要）；各特徵單位或尺度不同時，通常進一步標準化，否則單位大的變數會主宰結果。
2.計算共變異數矩陣。
3.特徵分解取得特徵值與特徵向量。
4.依特徵值降冪排序，計算解釋變異比例 λi/∑jλj。
5.以累積解釋變異或陡坡圖的轉折點決定保留維度數。
**PCA 降噪的程式判讀（114-2 L23 Q46）**：對雜訊影像使用 `PCA()` 而未指定 `n_components`，通常保留全部可用主成分；`transform` 後再 `inverse_transform` 幾乎只是重建原影像，無法期待靠捨棄低變異方向來抑制雜訊。應在建立 PCA 時選擇**少於原維度**的成分數（例如依重建品質與驗證資料調整 `n_components`），再投影與反向重建。成分保留過少也會抹去筆畫；若雜訊落在高變異方向，PCA 降維本身也不保證有效。參見 [scikit-learn PCA 參數文件](https://scikit-learn.org/stable/modules/generated/sklearn.decomposition.PCA.html)。
常見陷阱與錯誤觀念
•PCA是非監督式的，最大化特徵本身的變異，不保證保留對預測目標最有鑑別力的資訊。
•主成分是原特徵的線性組合，通常較難像單一原特徵那樣直接解釋；可檢視成分負荷量輔助說明。
•必須以訓練集擬合的投影矩陣去轉換測試集。

#### 2.1.5 考點補丁：t-SNE vs PCA 的用途邊界
核心必考

- **兩者的根本差異**：

  | | PCA | t-SNE |
  |---|---|---|
  | 類型 | **線性**降維 | **非線性**降維 |
  | 保留什麼 | **全域**變異（最大變異方向） | **局部**鄰域結構 |
  | 能否套用新資料 | 可以（有投影矩陣，可 transform 新資料；降維後以 inverse_transform 近似還原） | 標準非參數 t-SNE **沒有直接的 transform**；參數化或延伸方法另論 |
  | 距離可否解讀 | 保留的主成分空間可比較投影距離，但丟棄維度會損失原空間距離資訊 | **圖上群集之間的距離與大小不可直接解讀** |
  | 速度 | 常比 t-SNE 快，可用 SVD 求解 | 精確演算法成本高；Barnes-Hut 等近似法可加速，實際取決於資料量與實作 |
  | 隨機性 | 完整分解通常可重現（成分符號可能翻轉）；採隨機化 SVD 時須固定種子 | t-SNE 常受初始化與隨機種子影響，不同設定可得到不同圖 |

- **一句判斷規則**：題幹要求「降維後當特徵餵給下游模型」「需要對新資料做同樣轉換」「解釋變異來源」→ **PCA**；要求「只看二維視覺化、觀察是否有分群」→ **t-SNE**。
- **最常考的陷阱**：**t-SNE 圖上兩個群集之間的距離不代表相似度**。t-SNE 只保留局部鄰域，全域距離會被扭曲。因此「這兩個群集靠得近所以資料相似」是錯誤推論；「這兩個群集分開了」只能當作「可能存在分群」的提示，perplexity 設定不當時也會出現假群集，仍須以其他方法驗證。
- **其他易混點**：
  - **t-SNE 不是為下游建模設計的**。它是**視覺化工具**，降維結果不適合直接當特徵，因為它不保留全域結構且無法應用於新樣本。
  - **perplexity 是 t-SNE 的關鍵超參數**，大致對應「每個點考慮的有效鄰居數」（常用 5～50）。太小則碎片化，太大則群集糊在一起。
  - **UMAP** 是非線性降維的另一選擇，速度通常快於 t-SNE，且**可 transform 新資料**（保留部分全域結構），但不保證優於 t-SNE。
- **與 L23102「線性代數」的連結**：PCA 建構在特徵分解／SVD 之上（見 2.1.3），與 2.1.6 的 LDA 都是可直接套用於新資料、可用於特徵工程的線性降維方法；t-SNE 則否。
- **對應題號**：115-1 L23 Q06（正解 B，題幹＋正解）。

#### 2.1.6 考點補丁：線性判別分析（LDA）降維
核心必考

- **定義**：**線性判別分析（Linear Discriminant Analysis, LDA）** 是**監督式**線性降維方法。它找一組投影方向，使**類間距離最大化、類內變異最小化**（Fisher 準則），可視為「有標籤版的 PCA」。
- **與 PCA 的關鍵差別**：

  | | PCA | LDA |
  |---|---|---|
  | 監督 | **非監督**（不看標籤） | **監督**（使用類別標籤） |
  | 目標 | 保留最大變異 | **最大化類間／類內變異比** |
  | 降維上限 | 最多 min(n−1, d) 維 | **最多 C − 1 維**（C 為類別數） |
  | 適用 | 探索、壓縮、去相關 | 分類前的特徵抽取 |

- **降維上限 C − 1 是最常考的數字**：三類別問題最多降到 2 維；二類別問題最多降到 1 維（一條投影軸，正是 Fisher 線性判別）。
- **一句判斷規則**：題幹出現「有標籤、要降到能最好區分類別的維度」→ LDA；「沒有標籤、只想保留最多資訊」→ PCA。
- **易混點**：
  - **LDA 在此是降維方法，不是分類器**。同一名稱下 LDA 也可當分類器（假設各類別共變異數相等且資料常態），兩種用途要依題意分辨。
  - **機率式 LDA 分類器**假設各類別條件分布近似常態且共用共變異數矩陣；QDA 允許各類別共變異數不同。作為線性判別投影時，仍須檢查資料與估計是否穩定，但不能把「不常態就必須改用 QDA」當通則。
  - **PCA 用在有標籤資料上可能丟掉最有判別力的方向**：若類別差異的方向剛好變異很小，PCA 會把它當雜訊刪掉，LDA 則會刻意保留它。
- **對應題號**：115-1 L23 Q44（正解 B，題幹＋正解）。

#### 2.1.7 非負矩陣分解（NMF）：「非負」是逐元素非負
官方補充

- **定義**：**非負矩陣分解（Non-negative Matrix Factorization, NMF）** 把非負矩陣 X（m×n）近似分解為兩個非負矩陣的乘積：X ≈ WH，其中 W 為 m×k、H 為 k×n，k 遠小於 m 與 n。
- **「非負」的正確意義（學習指引勘誤 ERR-1150410-17）**：式中的 X ≥ 0、W ≥ 0、H ≥ 0 是線性代數對「非負矩陣」的標準簡寫，意思是**矩陣內每一個元素都 ≥ 0（element-wise non-negative）**，不是把整個矩陣當成一個數值來比較大小。
- **為什麼要非負**：分解結果由非負成分相加，避免正負值相互抵銷，因此常可作「部分」的解讀。例如把資料排成**文件×詞**矩陣 X（m 份文件×n 個詞），W（文件×主題）表示各文件的主題權重，H（主題×詞）的每一列表示一個主題的詞權重；人臉影像也可學得局部成分，但不保證每次都恰好對應眼、鼻、嘴。
- **一句判斷規則**：題幹出現「資料本身不可能為負（詞頻、像素、購買次數）」「希望分解結果可解讀為部分或主題」→ NMF；允許正負抵銷、追求最大變異 → PCA／SVD。
- **易混點**：
  - **PCA 的主成分可正可負**，因此無法做「部分相加」的解讀；NMF 則要求輸入矩陣不含負值（含負值時須先平移或改用其他方法）。
  - **NMF 沒有唯一解**，結果受初始化影響，實務上會固定隨機種子或用 NNDSVD 初始化。
  - k（成分數）是超參數，須依重建誤差與可解讀性選擇。

#### 2.1.8 學習指引補充：LSA、主題模型、OLS 與偽逆
官方補充

- **潛在語意分析（LSA）**：對「詞 × 文件」矩陣做 SVD，保留前 k 個奇異值，得到低維的語意空間，讓共現模式相近的詞彼此靠近。
- **主題模型（Latent Dirichlet Allocation）**：假設每篇文件是多個主題的混合、每個主題是詞的機率分布，用來找出語料中的主題。縮寫同為 LDA，但與 2.1.6 的**線性判別分析**完全不同。
- **最小平方法（OLS）與偽逆**：線性迴歸係數 β = (XᵀX)⁻¹Xᵀy；特徵完全共線時 XᵀX 不可逆，可改用以 SVD 計算的**偽逆** X⁺，得到最小範數的解。
- **線性變換**：矩陣乘法就是線性變換，可表示旋轉、縮放、投影；PCA 就是把資料投影到主成分方向上。
- **一句判斷規則**：「文件主題的機率組成」→ 主題模型（Latent Dirichlet Allocation）；「有標籤、要最大化類別可分性的降維」→ 線性判別分析；「XᵀX 不可逆」→ 偽逆或正則化。
- **易混點**：NMF 的逐元素非負見 2.1.7。
- **指引頁碼**：學習指引科目三 3-9、3-10、3-14～3-16。

### 2.2 程式判讀重點
核心必考
矩陣運算與維度

```python
A= np.random.rand(100, 20)#(100,20)
B= np.random.rand(20, 5)#(20,5)
C= A @ B #(100,5) 內側 20相同，合法
D= A * A #逐元素相乘（Hadamard），形狀不變 (100,20)
# E= A @ A # 錯誤：(100,20)@(100,20)內側 20!= 100 會拋出 ValueError
```

必考：@（或np.dot）是矩陣乘法，*是逐元素相乘。兩者語意完全不同，是本章最高頻的程式陷阱。

#### 2.2.1 考點補丁：NumPy 線性代數函式對照
核心必考

- **定義**：NumPy 的線性代數函式集中在 `np.linalg`，名稱都是英文縮寫，考題常把函式與功能對調。

  | 函式 | 計算什麼 |
  |---|---|
  | `np.linalg.inv(A)` | 反矩陣 A⁻¹（A 須為可逆方陣） |
  | `np.linalg.det(A)` | 行列式 |
  | `np.linalg.eig(A)` | 特徵值與特徵向量（回傳兩個結果） |
  | `np.linalg.svd(A)` | 奇異值分解 U、Σ、Vᵀ |
  | `np.dot(u, v)` 或 `u @ v` | 兩個一維向量時為內積（純量） |
  | `u * v` | 逐元素相乘，形狀不變 |

- **一句判斷規則**：先看函式名稱的縮寫：inv＝inverse（反矩陣）、det＝determinant（行列式）、eig＝eigen（特徵分解）。向量題則先分辨 `*` 與 `dot`。
- **計算範例**：u = [2, 0, 1]、v = [3, 4, 5]。`u * v` = [6, 0, 5]；`np.dot(u, v)` = 6 + 0 + 5 = 11；`u + v` = [5, 4, 6]。
- **易混點**：
  - 兩個一維向量的 `np.dot` 回傳**純量**；新版 NumPy 顯示為 `np.int64(11)` 這類帶型別的寫法，數值仍是 11。
  - 逐元素相加是 `+`，不要與 `*` 的結果混淆。
- **對應題號**：114-2 L23 Q40（正解 C，程式圖）。

### 2.3 常見陷阱與錯誤觀念
• 混淆@與*。前者矩陣乘法，後者逐元素。
• PCA 前未按資料尺度決定處置。資料至少需中心化；不同單位或尺度差異明顯時通常也要標準化，否則大尺度變數易主宰主成分。
• 以為 PCA一定提升效能。它是非監督的。
• 以歐氏距離做文本相似度。文件長度會主導結果，應用餘弦相似度。
• 以為餘弦相似度值域是 [0,1]。一般向量為 [−1,1]；只有全非負向量（如詞頻）才落在 [0,1]。

#### 模擬題 SIM-L23102-001

模擬題 SIM-L23102-001 ｜ 選型題 ｜ 難度：中級 ｜ 對應 L23102
某語意檢索系統需比較查詢句與文件的相似度。文件長度差異極大（從 50字到 5,000字）。下列相
似度度量何者最為適當？
(A)歐氏距離，因其為最標準的距離度量
(B)餘弦相似度，因其只比較向量方向而不受文件長度影響
(C)曼哈頓距離
(D)兩向量的內積，不做任何正規化
答案與逐項解析
答案：B
(A) ×歐氏距離受向量長度影響。長文件的向量範數大，即使主題與查詢完全相同，距離仍會很遠。
(B)✓正解。餘弦相似度以兩向量的範數作為分母正規化，只保留方向資訊，因此不受文件長短影
響。這正是它成為向量檢索預設度量的原因。
(C) ×曼哈頓距離同樣受向量長度影響。
(D) ×未正規化的內積會被長向量主導——長文件的內積天然較大，等於偏袒長文件。
干擾項設計理由：(D)是餘弦相似度的分子，測試考生是否理解分母正規化才是關鍵。
延伸考點：若向量事先已正規化為單位長度，內積即等於餘弦相似度，且與歐氏距離的排序一致。
許多向量資料庫因此在寫入時就先做正規化，以便用較快的內積運算取代餘弦計算。

#### 模擬題 SIM-L23102-002

模擬題 SIM-L23102-002 ｜ 程式判讀 ｜ 難度：中級 ｜ 對應 L23102
A形狀為(64,128)，B形狀為(128,10)。下列何者會拋出錯誤？
(A)A@ B
(B)A.T@ A
(C)A * B
(D)B.T @ B
答案與逐項解析
答案：C
(A) ×（合法）(64,128)·(128,10)，內側 128相同，結果 (64,10)。
(B) ×（合法）(128,64)·(64,128)，內側 64相同，結果 (128,128)。
(C)✓正解（會出錯）。*是逐元素相乘，要求兩陣列形狀相同或可廣播。(64,128)與 (128,10)既不
相同也無法廣播，故拋出錯誤。
(D) ×（合法）(10,128)·(128,10)，結果 (10,10)。
干擾項設計理由：(C)看起來最「簡單」，卻正是錯的——考的是@與*的語意差異，而非維度計算
難度。
延伸考點：神經網路一層的運算 Wx+ b用的是矩陣乘法；而注意力機制中的遮罩、Dropout的遮
罩則用逐元素相乘。兩者在同一段程式中並存，看錯符號會導致完全不同的行為。

#### 模擬題 SIM-L23102-003

模擬題 SIM-L23102-003 ｜ 觀念題（反向） ｜ 難度：中級 ｜ 對應 L23102
關於 PCA之敘述，下列何者錯誤？
(A) PCA對共變異數矩陣做特徵分解，特徵值大小代表該主成分解釋的變異量
(B)各特徵單位不同時，執行前應先標準化，否則單位大的變數會主宰主成分
(C)主成分為原特徵的線性組合，因此降維後仍可直接向業務單位說明每個維度的意義
(D) PCA為非監督式方法，不保證保留對預測目標最有鑑別力的資訊
答案與逐項解析
答案：C
(A)✓正確。
(B)✓正確。

正理解可解釋性的來源。

由。此時應改用特徵選擇（保留原始特徵）或可解釋模型。此議題與 Chapter 12的可解釋性要求直
接相關。

#### 模擬題 SIM-L23102-004

模擬題 SIM-L23102-004 ｜ 計算題 ｜ 難度：基礎 ｜ 對應 L23102
某 PCA結果的前五個特徵值依序為 λ = [40,25,15,12,8]（共五個成分）。若要保留累積解釋變異達
80%，至少須保留幾個主成分？
(A) 2個
(B) 3個
(C) 4個
(D) 5個
答案與逐項解析
答案：B
特徵值總和 = 40+25+15+12+8 = 100。
累積解釋變異：
1個 → 40/100 = 40%；
2個 → (40+25)/100 = 65%；
3個 → (40+25+15)/100 = 80%已達門檻。
(A) ×僅 65%，未達 80%。
(B)✓正解。
(C)(D) ×超出需求，未取「至少」。
延伸考點：實作上PCA(n_components=0.8)傳入小數即代表「累積解釋變異的目標比例」，會自動選出
3個成分；傳入整數n_components=3則是直接指定成分數。兩者語意不同，是程式題的常見考點（見
L22301）。

#### 模擬題 SIM-L23102-005

模擬題 SIM-L23102-005 ｜ 觀念題 ｜ 難度：基礎 ｜ 對應 L23102
非負矩陣分解（NMF）將資料矩陣 X 近似分解為 X ≈ WH，並要求 X ≥ 0、W ≥ 0、H ≥ 0。關於「≥ 0」的意義，下列何者正確？
(A)代表矩陣的行列式大於或等於 0
(B)代表矩陣內每一個元素都大於或等於 0
(C)代表矩陣所有元素的總和大於或等於 0
(D)代表矩陣的所有特徵值都大於或等於 0
答案與逐項解析
答案：B
(A) ×行列式是整個方陣的一個數值；NMF 的 W、H 通常不是方陣，且非負條件與行列式無關。
(B)✓正解。這是線性代數對「非負矩陣」的標準簡寫：逐元素非負（element-wise non-negative），不是把矩陣視為單一數值。此即學習指引勘誤 ERR-1150410-17 的更正內容。
(C) ×總和非負時仍可能有負元素，無法支撐 NMF「只能相加、不能抵銷」的部分解讀。
(D) ×特徵值非負是「半正定」的條件，屬另一個概念，且只對方陣有意義。
干擾項設計理由：(A)(C)(D)都把「矩陣 ≥ 0」誤讀成某一個純量的比較，正是勘誤所糾正的誤解。
延伸考點：NMF 的非負限制使每個成分可讀成「部分」或「主題」，這是它與 PCA（主成分可正可負）在可解釋性上的關鍵差異。

#### 模擬題 SIM-L23102-006

模擬題 SIM-L23102-006 ｜ 觀念與程式題 ｜ 難度：中級 ｜ 對應 L23102
某推薦系統工程師欲對使用者-商品評分矩陣（高維稀疏矩陣）進行矩陣分解以萃取潛在特徵（Latent Factors）。在比較標準 PCA 與截斷奇異值分解（TruncatedSVD）時，下列敘述何者最為正確？
(A) TruncatedSVD 支援稀疏矩陣（scipy.sparse）且運算時不需要先對資料矩陣進行全域中心化（Centering），因此特別適合高維稀疏資料（如文本 TF-IDF 或推薦評分）
(B) SVD 只能分解正方形且可逆的方陣，若資料筆數不等於特徵數則無法執行分解
(C) 奇異值矩陣 $\Sigma$ 的對角線元素（奇異值）可能為負數，其絕對值最小者代表最主要的資料變異方向
(D) TruncatedSVD 與標準 PCA 完全相同，均會強迫將稀疏矩陣填補 0 並轉為稠密矩陣（Dense Matrix）後再計算共變異數矩陣
答案與逐項解析
答案：A
(A)✓正解。標準 PCA 必須先將特徵中心化（減去均值），而將高維稀疏矩陣中心化會破壞其稀疏性（使原本大量的 0 變成非 0），導致記憶體耗盡。`sklearn.decomposition.TruncatedSVD` 直接在原始稀疏矩陣上執行分解，不強制中心化，因而在自然語言處理與推薦系統巨量稀疏矩陣降維中廣泛使用。
(B) ×SVD（奇異值分解）是線性代數中最通用的分解方法，適用於任意維度 $m \times n$ 的矩陣，無需滿足方陣或可逆條件。
(C) ×奇異值定義為半正定矩陣 $X^T X$（或 $X X^T$）特徵值的非負平方根，依常規由大到小排序且必然 $\ge 0$；奇異值越大代表對應奇異向量所解釋的訊號能量與變異量越大。
(D) ×標準 PCA 需中心化（破壞稀疏性），而 TruncatedSVD 專門針對稀疏格式設計，不需轉稠密矩陣。
干擾項設計理由：(B)混淆特徵分解（Eigendecomposition，僅限方陣）與 SVD（任意矩陣皆可）；(C)違背奇異值非負性與能量排序定義。
延伸考點：當輸入資料事先完成中心化時，TruncatedSVD 的結果與 PCA 產生的主成分方向完全等價。
