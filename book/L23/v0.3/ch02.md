### 2.1 .1內積與餘弦相似度

2.1.1內積與餘弦相似度
核心必考
cosθ = a· b∥a∥∥b∥
餘弦相似度為何是文本檢索的預設度量
餘弦相似度只看方向不看長度。兩份內容主題相同但長短懸殊的文件，其向量方向相近但長度差距
大——用歐氏距離會判定為不相似，用餘弦相似度則能正確判定為相似。
值域為 [−1,1]：1代表方向完全相同、0代表正交（無關）、−1代表方向相反。
補充：若向量已正規化為單位長度，餘弦相似度與歐氏距離具單調對應關係，兩者的排序結果相同。

### 2.1 .2矩陣乘法與維度相容

2.1.2矩陣乘法與維度相容
核心必考
神經網路的一層即為 y =σ(Wx+ b)。維度必須匹配：W為 m×n、x為 n×1、輸出為 m×1。
規則：(m×n)·(n×p) = (m×p)——內側維度必須相同，外側維度成為結果形狀。

### 2.1 .3特徵值、特徵向量與 SVD

2.1.3特徵值、特徵向量與 SVD
核心必考
Av =λv
特徵向量是「矩陣作用下方向不變、僅被縮放」的方向；特徵值 λ就是縮放倍率。
PCA即對共變異數矩陣做特徵分解——特徵值大小即該主成分所解釋的變異量。
奇異值分解（SVD）：A =UΣV⊤，任意矩陣皆可分解。應用於降維、推薦系統的潛在因子模型與低
秩近似。

### 2.1 .4PCA五步驟

2.1.4PCA五步驟
核心必考
1.標準化（必要步驟，否則單位大的變數主宰結果）。
2.計算共變異數矩陣。
3.特徵分解取得特徵值與特徵向量。
4.依特徵值降冪排序，計算解釋變異比例 λi/∑jλj。
5.以累積解釋變異或陡坡圖的轉折點決定保留維度數。
常見陷阱與錯誤觀念
•PCA是非監督式的，最大化特徵本身的變異，不保證保留對預測目標最有鑑別力的資訊。
•主成分是原特徵的線性組合，喪失可解釋性。
•必須以訓練集擬合的投影矩陣去轉換測試集。

### 2.1 .6考點補丁：t-SNE vs PCA 的用途邊界

2.1.6考點補丁：t-SNE vs PCA 的用途邊界
核心必考

- **兩者的根本差異**：

  | | PCA | t-SNE |
  |---|---|---|
  | 類型 | **線性**降維 | **非線性**降維 |
  | 保留什麼 | **全域**變異（最大變異方向） | **局部**鄰域結構 |
  | 是否可逆 | 可逆（有投影矩陣，可 transform 新資料） | **不可逆**，且**不能直接 transform 新資料** |
  | 距離可否解讀 | 主成分之間的距離有意義 | **圖上群集之間的距離與大小不可解讀** |
  | 速度 | 快（可用 SVD 精確解） | 慢（O(n²) 以上，需 Barnes-Hut 近似） |
  | 隨機性 | 確定性 | **隨機**，不同 random_state 得到不同圖 |

- **一句判斷規則**：題幹要求「降維後當特徵餵給下游模型」「需要對新資料做同樣轉換」「解釋變異來源」→ **PCA**；要求「只看二維視覺化、觀察是否有分群」→ **t-SNE**。
- **最常考的陷阱**：**t-SNE 圖上兩個群集之間的距離不代表相似度**。t-SNE 只保留局部鄰域，全域距離會被扭曲。因此「這兩個群集靠得近所以資料相似」是錯誤推論；「這兩個群集分開了」才是可信的訊號。
- **其他易混點**：
  - **t-SNE 不是為下游建模設計的**。它是**視覺化工具**，降維結果不適合直接當特徵，因為它不保留全域結構且無法應用於新樣本。
  - **perplexity 是 t-SNE 的關鍵超參數**，大致對應「每個點考慮的有效鄰居數」（常用 5～50）。太小則碎片化，太大則群集糊在一起。
  - **UMAP** 是非線性降維的另一選擇，速度通常快於 t-SNE，且**可 transform 新資料**（保留部分全域結構），但不保證優於 t-SNE。
- **與 L23102「線性代數」的連結**：PCA 建構在特徵分解／SVD 之上（見 2.1.3），是本章唯一可直接用於特徵工程的降維方法。
- **對應題號**：115-1 L23 Q06（正解 B，題幹＋正解）。

### 2.1 .7考點補丁：線性判別分析（LDA）降維

2.1.7考點補丁：線性判別分析（LDA）降維
核心必考

- **定義**：**線性判別分析（Linear Discriminant Analysis, LDA）** 是**監督式**線性降維方法。它找一組投影方向，使**類間距離最大化、類內變異最小化**（Fisher 準則），可視為「有標籤版的 PCA」。
- **與 PCA 的關鍵差別**：

  | | PCA | LDA |
  |---|---|---|
  | 監督 | **非監督**（不看標籤） | **監督**（使用類別標籤） |
  | 目標 | 保留最大變異 | **最大化類間／類內變異比** |
  | 降維上限 | 最多 min(n−1, d) 維 | **最多 C − 1 維**（C 為類別數） |
  | 適用 | 探索、壓縮、去相關 | 分類前的特徵抽取 |

- **降維上限 C − 1 是最常考的數字**：三類別問題最多降到 2 維；二類別問題最多降到 1 維（一條投影軸，正是 Fisher 線性判別）。
- **一句判斷規則**：題幹出現「有標籤、要降到能最好區分類別的維度」→ LDA；「沒有標籤、只想保留最多資訊」→ PCA。
- **易混點**：
  - **LDA 在此是降維方法，不是分類器**。同一名稱下 LDA 也可當分類器（假設各類別共變異數相等且資料常態），兩種用途要依題意分辨。
  - **LDA 假設各類別共變異數矩陣相同**，且資料近似常態。違反時改用二次判別分析（QDA）或其他方法。
  - **PCA 用在有標籤資料上可能丟掉最有判別力的方向**：若類別差異的方向剛好變異很小，PCA 會把它當雜訊刪掉，LDA 則會刻意保留它。
- **對應題號**：115-1 L23 Q44（正解 B，題幹＋正解）。

### 2.3 常見陷阱與錯誤觀念

2.3 常見陷阱與錯誤觀念
常見陷阱與錯誤觀念
• 混淆@與*。前者矩陣乘法，後者逐元素。
• PCA前忘記標準化。尺度大的變數主宰第一主成分。
• 以為 PCA一定提升效能。它是非監督的。
• 以歐氏距離做文本相似度。文件長度會主導結果，應用餘弦相似度。
• 以為餘弦相似度值域是 [0,1]。一般向量為 [−1,1]；只有全非負向量（如詞頻）才落在 [0,1]。

#### 模擬題 SIM-L23102-001

模擬題 SIM-L23102-001 ｜ 選型題 ｜ 難度：中級 ｜ 對應 L23102
某語意檢索系統需比較查詢句與文件的相似度。文件長度差異極大（從 50字到 5,000字）。下列相
似度度量何者最為適當？
(A)歐氏距離，因其為最標準的距離度量
(B)餘弦相似度，因其只比較向量方向而不受文件長度影響
(C)曼哈頓距離
(D)兩向量的內積，不做任何正規化
答案與逐項解析
答案：B
(A) ×歐氏距離受向量長度影響。長文件的向量範數大，即使主題與查詢完全相同，距離仍會很遠。
(B)✓正解。餘弦相似度以兩向量的範數作為分母正規化，只保留方向資訊，因此不受文件長短影
響。這正是它成為向量檢索預設度量的原因。
(C) ×曼哈頓距離同樣受向量長度影響。
(D) ×未正規化的內積會被長向量主導——長文件的內積天然較大，等於偏袒長文件。
干擾項設計理由：(D)是餘弦相似度的分子，測試考生是否理解分母正規化才是關鍵。
延伸考點：若向量事先已正規化為單位長度，內積即等於餘弦相似度，且與歐氏距離的排序一致。
許多向量資料庫因此在寫入時就先做正規化，以便用較快的內積運算取代餘弦計算。

#### 模擬題 SIM-L23102-002

模擬題 SIM-L23102-002 ｜ 程式判讀 ｜ 難度：中級 ｜ 對應 L23102
A形狀為(64,128)，B形狀為(128,10)。下列何者會拋出錯誤？
(A)A@ B
(B)A.T@ A
(C)A * B
(D)B.T @ B
答案與逐項解析
答案：C
(A) ×（合法）(64,128)·(128,10)，內側 128相同，結果 (64,10)。
(B) ×（合法）(128,64)·(64,128)，內側 64相同，結果 (128,128)。
(C)✓正解（會出錯）。*是逐元素相乘，要求兩陣列形狀相同或可廣播。(64,128)與 (128,10)既不
相同也無法廣播，故拋出錯誤。
(D) ×（合法）(10,128)·(128,10)，結果 (10,10)。
干擾項設計理由：(C)看起來最「簡單」，卻正是錯的——考的是@與*的語意差異，而非維度計算
難度。
延伸考點：神經網路一層的運算 Wx+ b用的是矩陣乘法；而注意力機制中的遮罩、Dropout的遮
罩則用逐元素相乘。兩者在同一段程式中並存，看錯符號會導致完全不同的行為。

#### 模擬題 SIM-L23102-004

模擬題 SIM-L23102-004 ｜ 計算題 ｜ 難度：基礎 ｜ 對應 L23102
某 PCA結果的前五個特徵值依序為 λ = [40,25,15,12,8]（共五個成分）。若要保留累積解釋變異達
80%，至少須保留幾個主成分？
(A) 2個
(B) 3個
(C) 4個
(D) 5個
答案與逐項解析
答案：B
特徵值總和 = 40+25+15+12+8 = 100。
累積解釋變異：
1個 → 40/100 = 40%；
2個 → (40+25)/100 = 65%；
3個 → (40+25+15)/100 = 80%已達門檻。
(A) ×僅 65%，未達 80%。
(B)✓正解。
(C)(D) ×超出需求，未取「至少」。
延伸考點：實作上PCA(n_components=0.8)傳入小數即代表「累積解釋變異的目標比例」，會自動選出
3個成分；傳入整數n_components=3則是直接指定成分數。兩者語意不同，是程式題的常見考點（見
L22301）。
