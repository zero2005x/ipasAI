### 1.1 核心概念與技術原理

<!-- pdf-page 16 -->
#### 1.1.1 損失函數不是任選的
核心必考
多數損失函數可由最大概似估計推導而來——你對雜訊分佈的假設，決定了該用哪個損失。
| 條件分布假設 | 對應損失 | 任務 | 特性 |
|---|---|---|---|
| 高斯（常態） | 均方誤差（MSE） | 迴歸 | 大誤差經平方放大 |
| 拉普拉斯 | 平均絕對誤差（MAE） | 迴歸 | 較不強調極端誤差；誤差為 0 時不可微 |
| 伯努利 | 二元交叉熵 | 二元分類 | 常配合 sigmoid 輸出 |
| 類別分布 | 類別交叉熵 | 多元單標籤分類 | 常配合 softmax 輸出 |
Huber Loss結合兩者：誤差小時用平方（可微、收斂快），誤差大時轉為線性（抗離群值），以 δ控制切換點。
:::tip 選型訊號
題幹出現「資料含離群值且不宜刪除」「希望模型不被極端值主導」→ MAE或 Huber。

題幹出現「誤差需可微、追求收斂速度」→ MSE。

神經網路分類以交叉熵為標準選擇（SVM 用 hinge loss），而非 MSE——用 MSE 做分類會使梯度在飽和區極小，訓練停滯。
:::

#### 1.1.2 貝氏定理與偽陽性弔詭
核心必考
P(A|B) = P(B|A) × P(A) ÷ P(B)
必考計算：低盛行率下的陽性預測值
某疾病盛行率 1%，檢測靈敏度（召回率）99%、特異度 95%。若某人檢測為陽性，實際患病機率為何？

取 10,000人：患病 100人 →檢出 100× 99% = 99人（真陽性）；未患病 9,900人 →偽陽性9,900×5% = 495人。
陽性者中真正患病的比例（即精確率／陽性預測值）
= 99 ÷ (99 + 495) = 99 ÷ 594 ≈ 16.7%
結論：即使模型指標亮眼，在低盛行率情境下陽性預測值仍可能極低。這解釋了為何詐欺偵測、罕病篩檢、資安告警會產生大量誤報，也是「準確率高但沒用」的數學根源。

#### 1.1.3 單純貝氏
官方補充
「單純」在於假設所有特徵條件獨立。此假設在現實中幾乎不成立（文本中的詞彼此相關），但模型在文本分類上仍表現良好，且訓練極快、對小樣本穩健。
:::trap 常見陷阱與錯誤觀念
考題常問「單純貝氏的假設是否合理」。標準答案是：假設通常不成立，但模型仍實用——因為分類只需要正確的相對排序，不需要準確的機率絕對值。也因此，單純貝氏輸出的機率校準不佳，不宜直接用於期望損失計算。
:::
<!-- pdf-page 17 -->
#### 1.1.4 偏差-變異分解
核心必考
期望誤差 =偏差² +變異+不可約誤差
| 狀況 | 常見徵狀 | 可評估的對策 |
|---|---|---|
| 高偏差／欠擬合 | 訓練與驗證誤差都高且接近 | 檢查特徵、標籤與模型容量；必要時減弱正則化或延長訓練 |
| 高變異／過擬合 | 訓練誤差低、驗證誤差高且差距大 | 檢查切分；評估資料增強、正則化、早停或簡化模型 |
| 不可約誤差 | 資料本身含無法完全預測的雜訊 | 改善可觀測特徵與標籤品質，但無法僅靠換模型消除全部雜訊 |
學習曲線診斷：規劃師的關鍵決策
畫出訓練誤差與驗證誤差隨樣本量變化的曲線：
兩線都高且已接近 →可能欠擬合；先查特徵、標籤與模型容量，增加資料未必是優先解法。

兩線間距大且尚未接近 →可能過擬合；增加具代表性的資料可能有幫助，仍須用驗證集確認。

這個判斷直接決定要「花錢買資料」還是「花時間換模型」。

#### 1.1.5 考點補丁：蒙地卡羅方法
核心必考

- **定義**：**蒙地卡羅方法（Monte Carlo method）** 是用**隨機抽樣**估計數值結果的一類演算法。核心思想是：當解析解不可得或太貴時，用大量隨機樣本的統計量逼近答案。
- **基本流程**：定義輸入的機率分布 → 從分布中抽樣 → 對每組樣本計算目標函數 → 彙總結果（取平均、分位數等）→ 以樣本數控制誤差。
- **一句判斷規則**：題幹出現「解析解不可得」「要估計某事件發生的機率或期望值」「用隨機模擬大量情境」→ 蒙地卡羅。
- **誤差收斂**：蒙地卡羅的誤差約與 **1/√N** 成正比。因此樣本數增加 100 倍，精度只提升 10 倍——這是它最大的限制，也是「提高精度要付出平方級成本」的原因。
- **與 MLE／MAP 的關係**：MLE 求最大概似參數、MAP 加入先驗求最大後驗；當後驗分布無法解析求解時，改用**蒙地卡羅**（如 MCMC、Gibbs 抽樣）從後驗中抽樣，再以樣本統計量估計參數與不確定性。
- **Bootstrap 與蒙地卡羅的差別**：**Bootstrap 是從既有樣本中「有放回重抽」**，用於估計統計量的抽樣分布；**蒙地卡羅是從假設的機率分布中抽樣**，用於模擬整個資料生成過程。前者不需要假設分布，後者需要。
- **常見應用**：風險值（VaR）估計、選擇權定價、貝氏後驗推論、強化學習的 rollout、不確定性傳播。
- **用模擬估計條件機率**：P(A | B) = P(A∩B) ÷ P(B)，模擬時兩個機率的分母（總次數）會約掉，所以只要「A 與 B 同時發生的次數 ÷ B 發生的次數」。分母是**條件事件 B**，不是 A，也不是兩者的次數相加或相乘。

  ```python
  import numpy as np
  rng = np.random.default_rng(0)
  x = rng.integers(1, 7, size=100_000)   # 模擬擲骰
  A = x % 3 == 0                         # 事件 A：3 的倍數
  B = x >= 4                             # 事件 B：大於等於 4
  p = (A & B).sum() / B.sum()            # P(A | B) ≈ 1/3（{6} ÷ {4,5,6}）
  ```

- **易混點**：
  - **蒙地卡羅不是「隨機猜」**。它有收斂保證，且誤差可以被估計。
  - **蒙地卡羅多用於「積分」**。求期望值本質上是求積分，這是它最廣泛的用途。
  - **隨機數品質會影響結果**。低差異序列（quasi-Monte Carlo）可改善收斂速度。

#### 1.1.6 考點補丁：單純貝氏的先驗與類別條件機率
核心必考

- **定義**：單純貝氏以 P(類別 | 特徵) ∝ P(類別) × Π P(特徵ᵢ | 類別) 做分類。P(類別) 是**先驗機率**，P(特徵ᵢ | 類別) 是**類別條件機率**，兩者都直接從訓練資料的次數估計。
- **一句判斷規則**：模型把某類正常樣本誤判為另一類，而原因是「某些詞在訓練資料裡幾乎只出現在另一類」→ 問題出在**訓練資料分布造成的條件機率偏高**。對策是補充或重新平衡訓練資料（例如加入含這些詞的正常樣本）、調整先驗機率或決策門檻。
- **拉普拉斯平滑**：若某詞在某類別從未出現，P(詞 | 類別) = 0，整個乘積歸零。加一平滑（每個計數加 1）可避免這種「一票否決」。
- **易混點**：
  - 單純貝氏是機率計數模型，**沒有 epoch 可調**，也**不需要特徵縮放**；「增加 epoch」或「先做標準化」都不是對策。
  - 訓練準確率高、上線後在特定子群出錯，未必是過擬合，常見原因是訓練資料沒有涵蓋上線後的分布。
  - 條件獨立假設不成立不代表模型不能用（見 1.1.3），不必因此整個換掉演算法。

#### 1.1.8 學習指引補充：PMF／PDF 與貝氏推論的名詞
官方補充

- **PMF 與 PDF**：離散隨機變數用機率質量函數（PMF），P(X = x) 就是機率且不超過 1；連續隨機變數用機率密度函數（PDF），密度可以大於 1，區間機率要對密度積分。累積分布函數（CDF）F(x) = P(X ≤ x) 兩者皆適用。
- **貝氏推論的三個名詞**：**先驗** P(θ) 是看資料前對參數的信念；**概似** P(資料 | θ) 衡量參數能多好地解釋資料；**後驗** P(θ | 資料) ∝ 概似 × 先驗，是看完資料後更新的信念。
- **參數估計**：點估計給單一數值（如 MLE、MAP，見 4.1.4）；區間估計給一個範圍與信心水準（如信賴區間、自助法百分位區間）。
- **一句判斷規則**：「看完資料後更新對參數的看法」→ 後驗；「只問哪個參數最能解釋資料」→ 概似最大化（MLE）。
- **易混點**：常見機率分佈的辨識見 1.1.7；後驗與概似不同，概似對 θ 積分不必等於 1。
- **指引頁碼**：學習指引科目三 3-3、3-4、3-6、3-7。

#### 1.1.9 學習指引補充：顯著水準與兩類錯誤
官方補充

- **假設檢定的基本邏輯**：先假設虛無假設 H₀（通常是「沒有差異、沒有效果」）成立，計算在此前提下觀察到目前或更極端結果的機率，即 **p 值**；p 值小於**顯著水準 α** 時拒絕 H₀。
- **顯著水準 α**：事先設定、可容忍的**型一錯誤**機率，也就是 H₀ 其實為真卻被拒絕（偽陽性）的機率，常用 0.05 或 0.01。
- **型二錯誤 β**：H₀ 其實為假卻未被拒絕（偽陰性）；1 − β 稱為**檢定力**。在其他條件不變時，α 調小會使 β 變大。
- **一句判斷規則**：問「α 代表什麼」→ 可容忍的型一錯誤機率；問「p < α 代表什麼」→ 結果在 α 水準下統計顯著，應拒絕 H₀。
- **易混點**：p 值不是「H₀ 為真的機率」；統計顯著也不等於實務上重要。模型比較時的型一、型二錯誤，與分類模型的偽陽性、偽陰性是同一組概念（見 9.1.1）。
- **指引頁碼**：學習指引科目三第三章（機器學習基礎數學）章末練習 3-29。

### 1.2 程式判讀重點
核心必考
ddof與變異數計算

```python
import numpy as np
import pandas as pd
x = np.array([1, 2, 3, 4, 5])
np.var(x)#ddof=0->母體變異數，分母n
np.var(x,ddof=1)#樣本變異數，分母n-1（不偏估計）

pd.Series(x).std()#同上，ddof=1
```

### 1.3 常見陷阱與錯誤觀念
• 分類任務用 MSE。應用交叉熵；MSE配 sigmoid會在飽和區梯度消失。
• 忽略盛行率談精確率。低盛行率下高召回率仍可能伴隨極低的陽性預測值。
• 把單純貝氏的機率當成校準良好的機率。只適合排序，不適合直接算期望值。
• 把「加資料」當萬用解。高偏差時無效。
• 混淆ddof預設值。numpy是 0，pandas是 1。
• 以為不可約誤差可以消除。它決定了效能天花板。

#### 模擬題 SIM-L23101-001

模擬題 SIM-L23101-001 ｜ 計算題 ｜ 難度：整合 ｜ 對應 L23101
某罕見疾病盛行率為 2%。篩檢工具的靈敏度（召回率）為 95%、特異度為 90%。若某人篩檢結果為陽性，其實際患病機率最接近下列何者？
(A) 95%
(B) 90%
(C) 16%
(D) 2%
答案與逐項解析
答案：C
取 10,000人：
患病 200人 →真陽性 200×0.95 = 190。

未患病 9,800人 →偽陽性 9,800×(1−0.90) = 980。

陽性預測值 = 真陽性 ÷（真陽性 + 偽陽性）= 190 ÷ (190 + 980) = 190 ÷ 1,170 ≈ 16.2%。
(A) × 95%是靈敏度（在患病者中檢出的比例），方向與題目所問相反。
(B) ×忽略盛行率的算法：0.95 ÷ (0.95 + 0.10) ≈ 90%。這等於假設患病與未患病人數相同，正是基率謬誤。
(C)✓正解。
(D) × 2%是先驗盛行率；檢測為陽性後機率已由 2%提升至約 16%，但仍遠低於直覺。
干擾項設計理由：(A)是最強誘答——把「檢出率」誤讀為「檢出後的患病率」，即混淆 P(陽性|患病)與 P(患病|陽性)。
延伸考點：此即基率謬誤。盛行率越低，偽陽性佔陽性結果的比例越高。實務上的因應是兩階段篩檢——先以高靈敏度工具初篩，再以高特異度工具複檢，可大幅提升陽性預測值。

#### 模擬題 SIM-L23101-002

模擬題 SIM-L23101-002 ｜ 診斷題 ｜ 難度：中級 ｜ 對應 L23101
某模型的訓練集 MAE為 8.2、驗證集 MAE為 8.5，兩條學習曲線在樣本量達 5萬後已趨於平坦並貼合。業務目標要求 MAE低於 4。下列處置何者最為適當？
(A)蒐集更多訓練資料至 50萬筆
(B)此為高偏差（欠擬合）：兩線皆高且已收斂，增加資料幫助有限；應提高模型複雜度、增加更有資訊量的特徵，或減弱正則化
(C)加強 L2正則化並提高 Dropout比例
(D)使用早停以避免過擬合
答案與逐項解析
答案：B
(A) ×兩線已收斂在一起，代表模型的表達能力已達極限；再多同類資料仍學不出更低的誤差。
(B)✓正解。訓練誤差與驗證誤差皆高且接近是高偏差的教科書徵狀。正確方向是增加模型容量或特徵資訊量。
(C) ×正則化與 Dropout是對付過擬合的手段；在欠擬合時加強只會讓模型更學不動。
(D) ×早停同樣針對過擬合；本例訓練誤差本身就高，提早停止只會更糟。
干擾項設計理由：(C)(D)都是「正確但用錯場合」的處方，測試考生能否先完成診斷再開藥。
延伸考點：若兩線間距大且未收斂（訓練 2.0、驗證 8.5），才是高變異，此時 (A)(C)(D)反而都是合理方向。務必先看兩條曲線的高度與間距再決定。

#### 模擬題 SIM-L23101-003

模擬題 SIM-L23101-003 ｜ 選型題 ｜ 難度：中級 ｜ 對應 L23101
某房價預測模型的訓練資料中含少數豪宅成交紀錄（價格為一般住宅的數十倍），且這些紀錄為真實有效資料不可刪除。若希望模型不被這些極端值過度主導，下列損失函數何者最為適當？
(A)均方誤差（MSE）
(B)平均絕對誤差（MAE）或 Huber Loss
(C)二元交叉熵
(D)類別交叉熵
答案與逐項解析
答案：B
(A) × MSE對誤差取平方，豪宅的巨大誤差會被放大數十倍，模型會為了壓低這幾筆的誤差而犧牲大多數一般住宅的準確度。
(B)✓正解。MAE對誤差取絕對值，極端值的影響是線性而非平方，較穩健；Huber Loss則在小誤差區用平方（保有可微性與收斂速度）、大誤差區轉為線性（抗離群值），兼顧兩者。
(C) ×二元交叉熵用於二元分類，房價預測是迴歸任務。
(D) ×類別交叉熵用於多元分類。
干擾項設計理由：(A)是迴歸任務的預設選擇，測試考生能否依離群值情境調整。
延伸考點：損失函數的選擇對應雜訊分佈假設——MSE假設高斯雜訊，MAE假設拉普拉斯雜訊（尾部較厚，因此容忍極端值）。另一種作法是對目標變數取對數後再用 MSE，這在右偏的金額類目標上很常見。

#### 模擬題 SIM-L23101-004

模擬題 SIM-L23101-004 ｜ 程式判讀 ｜ 難度：基礎 ｜ 對應 L23101
關於下列程式之敘述，何者錯誤？

```python
import numpy as np, pandas as pd
x= [2, 4, 4, 4, 5, 5, 7, 9]
a= np.var(x)
b= pd.Series(x).var()
```

(A)a為母體變異數，分母為 n
(B)b為樣本變異數，分母為 n−1
(C)a的值小於b
(D)a與b必定相等，因為兩者計算的是同一組資料
答案與逐項解析
答案：D
(A)✓正確。numpy.var預設`ddof=0`。
(B)✓正確。pandas的`var()`預設`ddof=1`。
(C)✓正確。分子相同而a的分母較大（n = 8對 n−1 = 7），故a較小。
(D) ×錯誤（即為答案）。兩者分母不同，數值必然不同。本例 a = 4.0、b≈ 4.571。
延伸考點：貝索校正（n−1）的目的是使樣本變異數成為母體變異數的不偏估計。n很大時兩者差異可忽略，但小樣本差異明顯。同樣的ddof陷阱也出現在`std()`，且在 L22101的敘述統計中已出現過一次。

模擬題 SIM-L23101-005 ｜ 觀念題 ｜ 難度：中級 ｜ 對應 L23101
關於單純貝氏分類器之敘述，下列何者最為正確？
(A)其條件獨立假設在文本分類中完全成立，因此效果良好
(B)該假設通常不成立，但因分類只需正確的相對排序，模型仍實用；惟其輸出機率校準不佳，不宜直接用於期望損失計算
(C)因假設不成立，故此模型在任何情境下皆不應使用
(D)單純貝氏需要大量訓練樣本才能收斂，不適合小樣本情境
答案與逐項解析
答案：B
(A) ×文本中的詞彼此高度相關（「機器」與「學習」常同時出現），條件獨立假設明顯不成立。
(B)✓正解。完整涵蓋三點：假設不成立、分類仍有效（只需排序正確）、機率校準不佳（不可直接當機率用）。

#### 模擬題 SIM-L23101-006

模擬題 SIM-L23101-006 ｜ 計算與觀念題 ｜ 難度：中級 ｜ 對應 L23101
某資料科學家對標準化後的 4 個特徵進行主成分分析（PCA），計算特徵共變異數矩陣得到其 4 個特徵值（Eigenvalues）依序為：$\lambda_1 = 2.4, \lambda_2 = 1.0, \lambda_3 = 0.4, \lambda_4 = 0.2$。若欲保留總變異量達到 85% 以上的資訊，下列分析與決策何者最為正確？
(A) 標準化後特徵總變異量等於特徵數之和（4.0）；前兩個主成分的累積變異解釋率為 $(2.4+1.0)/4.0 = 85\%$，故僅需選取前 2 個主成分即可滿足門檻
(B) 特徵值總和在數學上固定為 1.0，題幹給予的特徵值數值有誤，無法計算
(C) 第一主成分（PC1）解釋了 $2.4 / 4.0 = 60\%$ 的變異，故僅需 1 個主成分即滿足 85% 需求
(D) 主成分分析投影後各主成分之間仍具有高度線性相關性，需要進一步執行特徵選取以消除共線性
答案與逐項解析
答案：A
(A)✓正解。資料先經標準化（Standardization）後，特徵共變異數矩陣即為相關係數矩陣，其對角線元素（各特徵變異數）皆為 1，特徵值總和等於變異數總和 $\sum \lambda_i = 4.0$。前兩個主成分之累積解釋變異量為 $(2.4 + 1.0) / 4.0 = 3.4 / 4.0 = 85\%$，剛好達成 85% 之降維保留門檻。
(B) ×特徵值總和等於原始標準化特徵的總變異數（特徵個數 $p=4$），而非固定為 1.0；將各特徵值除以總和後得到各成分的解釋比率，其總和方為 1.0（100%）。
(C) ×第一主成分僅解釋 60%，未達 85% 門檻，必須納入第二主成分（累積達 85%）。
(D) ×PCA 的數學性質保證：相異特徵值對應的正交特徵向量所投射出的各主成分之間彼此正交且共變異數為 0（線性不相關），不具線性共線性。
干擾項設計理由：(B)混淆特徵值本身數值與變異解釋比例；(D)忽視 PCA 正交解耦的核心數學特性。
延伸考點：Kaiser 準則（Kaiser Criterion）建議保留特徵值大於 1.0 的主成分（本例中 $\lambda_1, \lambda_2 \ge 1.0$），代表該主成分所含資訊量大於單一原始特徵。
