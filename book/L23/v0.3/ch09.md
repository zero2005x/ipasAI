### 9.1 .1混淆矩陣

9.1.1混淆矩陣
核心必考
預測為正 預測為負
實際為正 TP（真陽性） FN（偽陰性，漏檢）
實際為負 FP（偽陽性，誤報） TN（真陰性）
五個公式與其分母（必背）
• Accuracy = TP +TNTP +TN +FP +FN
• Precision（精確率） = TPTP +FP ——「我說是正的，有幾成真的是正的」，分母是所有預測為
正者。
• Recall（召回率／靈敏度） = TPTP +FN ——「真正是正的，我抓到幾成」，分母是所有實際為
正者。
• Specificity（特異度） = TNTN +FP
• F1 = 2PRP +R——精確率與召回率的調和平均，任一項極低則 F1就低。
記憶法：Precision的分母是「Predicted為正」；Recall的分母是「Real為正」。
官方勘誤：Recall公式
官方已公告《AI應用規劃師（中級）學習指引內容勘誤》。其中影響最大者為召回率公式：
正確為 Recall = TPTP +FN。
部分學習指引版本誤植為 TP/(TP +FP)——該式實為精確率。作答時一律以正確公式為準。
本書全冊之指標計算均採正確公式，並於各處交叉驗算。 版本敏感

### 9.1 .2閾值、ROC與 PR曲線

9.1.2閾值、ROC與 PR曲線
核心必考
模型輸出的是連續分數，0.5只是預設閾值而非最佳值。
方向性必背
調高閾值 ⇒預測為正者變少 ⇒ Precision上升、Recall下降。
調低閾值 ⇒相反。
漏檢代價高（癌症篩檢、瑕疵檢測、詐欺偵測）→優先 Recall，調低閾值。
誤報代價高（誤刪重要郵件、自動封鎖帳號）→優先 Precision，調高閾值。
ROC曲線以真陽性率（即 Recall）對偽陽性率作圖；AUC為其下面積，可解讀為「隨機取一正一負
樣本，模型給正樣本較高分數的機率」。AUC = 0.5等同亂猜。
PR曲線以 Precision對 Recall作圖。
極度不平衡時 AUPRC優於 AUROC
偽陽性率 =FP/(FP +TN)。在極度不平衡下 TN極大，即使 FP增加不少，偽陽性率的變動仍
很小，因此 AUROC會顯得過於樂觀。
PR曲線的橫縱軸都聚焦於少數類（兩者皆不含 TN），對少數類的表現變化更敏感，故 AUPRC
更具鑑別力。

### 9.1 .5六大資料洩漏來源

9.1.5六大資料洩漏來源
核心必考
常見陷阱與錯誤觀念
1. 前處理在切分前執行（標準化、插補、降維、特徵選擇）。
2. 重採樣在切分前執行——合成樣本同時進入訓練與測試集。
3. 目標編碼未做折外計算——標籤資訊直接洩漏至特徵。
4. 時序資料隨機切分——用未來預測過去。
5. 分組資料未用 Group K-Fold——同一病患的多筆紀錄跨折。
6. 以測試集反覆調參——測試集實質退化為驗證集，最終效能被高估。
最強警訊：離線指標好到不真實（如 AUC > 0.99），或某個特徵的重要性異常獨大。此時應立刻檢
查該特徵是否為標籤的變形。

### 9.1 .8考點補丁：標籤偏差（Label Bias）

9.1.8考點補丁：標籤偏差（Label Bias）
核心必考

- **定義**：**標籤偏差**指訓練標籤本身**系統性地偏離真實目標**，使模型學到錯誤的對應關係。它與特徵偏差不同——特徵偏差是輸入有偏，標籤偏差是**答案有偏**。
- **四種常見來源**：

  | 來源 | 說明 | 例子 |
  |---|---|---|
  | **代理標籤（proxy label）** | 用容易取得的指標代替真正想預測的目標 | 用「是否被逮捕」代替「是否犯罪」 |
  | **標註者偏誤** | 標註者的主觀標準不一致或帶有偏見 | 不同醫師對同一影像的判讀不同 |
  | **歷史決策偏誤** | 標籤來自過去的決策，而決策本身有偏 | 用「過去核准的貸款」當好客戶標籤 |
  | **標籤洩漏（label leakage）** | 特徵中含有標籤的結果資訊 | 用「催收次數」預測「是否違約」 |

- **一句判斷規則**：題幹出現「模型在離線表現很好但上線後失效」、「標籤是從歷史紀錄取得的」→ 檢查標籤偏差；出現「特徵中有未來才會知道的資訊」→ 標籤洩漏（屬第 8 章資料洩漏）。
- **為什麼最危險**：標籤偏差**不會讓離線指標變差**，反而常常讓指標變好（因為模型確實學會了預測那個有偏的標籤）。因此無法用驗證集發現，必須靠**對標籤生成過程的審查**。
- **處理方式**：
  1. **審查標籤的定義與生成流程**，確認它是否真的是想預測的目標。
  2. **改用更接近真實目標的標籤**（如以實際還款紀錄取代核准紀錄）。
  3. **量化標註者一致性**（如 Cohen's kappa）；一致性低時須重新制定標註準則。
  4. **檢查特徵的時間點正確性**，排除標籤洩漏。
- **易混點**：
  - **標籤偏差 ≠ 類別不平衡**。不平衡是各類別數量差距大但標籤正確；標籤偏差是標籤本身就錯。
  - **標籤偏差 ≠ 取樣偏差**。取樣偏差是「哪些樣本被收進來」有偏；標籤偏差是「答案」有偏。
  - **修正標籤偏差通常需要重新收集標籤**，不是調參或換模型能解決的。
- **對應題號**：114-2 L23 Q13（正解 B，題幹）。

### 9.1 .9考點補丁：殘差圖判讀——異質變異

9.1.9考點補丁：殘差圖判讀——異質變異
核心必考

- **定義**：**異質變異（heteroscedasticity）** 指殘差的**變異數隨預測值（或自變數）改變**，違反線性迴歸「殘差變異數固定（同質變異）」的假設。
- **殘差圖的標準讀法**（橫軸為預測值 ŷ，縱軸為殘差 e = y − ŷ）：

  | 圖形特徵 | 代表的問題 |
  |---|---|
  | 隨機散布在 0 附近，無明顯形狀 | 假設成立 ✅ |
  | **漏斗形（左窄右寬或左寬右窄）** | **異質變異** |
  | 明顯曲線（U 形、倒 U 形） | 線性假設不成立，需加非線性項 |
  | 殘差隨時間呈現規律 | 自相關（時序資料） |
  | 少數點遠離主群 | 離群值或高槓桿點 |

- **一句判斷規則**：題幹出現「殘差圖呈漏斗狀」「誤差隨預測值增大而變大」→ 異質變異。
- **後果**：
  1. **係數估計仍是不偏的**，但**不再是有效估計**（變異數最小）。
  2. **標準誤被低估**，導致 t 值偏大、p 值偏小 → **假陽性增加**（把不顯著的變數判為顯著）。
  3. 信賴區間與預測區間不可靠。
- **處理方式**：
  - **加權最小平方法（WLS）**：以殘差變異數的倒數為權重。
  - **穩健標準誤（robust standard errors）**：修正標準誤但不改變係數。
  - **變數轉換**：對目標取對數常能穩定變異數（但見 7.1.6 對數轉換何時有害）。
- **易混點**：
  - **異質變異不影響預測值本身**，只影響推論（顯著性檢定與信賴區間）。若目的只是預測，可以不處理。
  - **殘差圖不是看 R²**。R² 高也可能有嚴重異質變異。
  - **與「殘差非常態」是兩件事**。異質變異是變異數不固定，常態性是分布形狀；兩者要分別檢查。
- **對應題號**：115-1 L23 Q05（正解 C，題幹＋正解）。

### 9.3 常見陷阱與錯誤觀念

9.3 常見陷阱與錯誤觀念
常見陷阱與錯誤觀念
• Precision與 Recall的分母錯置。本章第一名失分點。
• 沿用被勘誤的 Recall公式。
• 閾值方向記反。漏檢貴應調低閾值。
• 極度不平衡用 Accuracy驗收。全猜多數類即可得高分。
• 不平衡時只看 AUROC。應改看 AUPRC。
• 以為 R2必為正。模型比猜平均值還差時為負。
• 時序資料用隨機切分。
• 分組資料未用 Group K-Fold。
• 以測試集反覆調參。測試集只能用一次。
• 把cross_val_score的回傳當成單一分數。
• 誤讀confusion_matrix的元素順序。

#### 模擬題 SIM-L23303-001

模擬題 SIM-L23303-001 ｜ 計算題 ｜ 難度：中級 ｜ 對應 L23303
某詐欺交易偵測模型在測試集上的混淆矩陣為：TP = 180、FP = 120、FN = 20、TN = 9,680。
下列敘述何者正確？
(A) Precision為 0.90，Recall為 0.60
(B) Precision為 0.60，Recall為 0.90，F1約為 0.72
(C) Accuracy為 0.986，故此模型效能優異，可直接上線
(D)若欲進一步降低漏檢，應調高分類閾值
答案與逐項解析
答案：B
Precision = TPTP +FP = 180300 = 0.60
Recall = TPTP +FN = 180200 = 0.90
F1 = 2×0.60×0.900.60+0.90 = 1.081.5 = 0.72
(A) ×兩者對調，是最典型的分母錯置。
(B)✓正解。
(C) × Accuracy = (180+9680)/10000 = 0.986數值雖高，但正負比為 1:49，全部預測為「非詐欺」
即可得 0.98。極度不平衡下 Accuracy是無效指標；且 Precision僅 0.60意味每 10件警示中
有 4件誤報。
(D) ×方向相反。調高閾值會使預測為正者變少，Recall下降、漏檢增加。欲降低漏檢應調低閾值。
延伸考點：業務成本計算——若每筆漏檢損失 8萬元、每筆誤報審查成本 500元，目前期望成本
= 20× 80,000 + 120× 500 = 1,660,000元。若調低閾值使 FN 降至 10、FP 升至 300，成本為
10×80,000+300×500 = 950,000元，顯然更優。最佳閾值應由成本函數決定而非固定為 0.5。

#### 模擬題 SIM-L23303-002

模擬題 SIM-L23303-002 ｜ 程式判讀 ｜ 難度：中級 ｜ 對應 L23303
執行下列程式後，print會輸出什麼型別？
1scores= cross_val_score(model, X, y, cv=5)
2print(scores)
(A)單一浮點數，即五折的平均分數
(B)長度為 5的陣列，每折一個分數；須自行呼叫.mean()取平均
(C)一個 DataFrame，含各折的詳細指標
(D)訓練完成的模型物件
答案與逐項解析
答案：B
(A) ×這是最常見的誤解。函式名稱雖為單數score，回傳的卻是每折的分數陣列。

(D) ×cross_val_score不會回傳訓練好的模型；每折的模型在評估後即被丟棄。要取得最終模型須
另行fit。
干擾項設計理由：(D)針對「跑完交叉驗證就有模型了」的誤解——這也是實務上常見的流程疏漏。
延伸考點：正確的報告方式是「五折平均 0.83、標準差 0.02」。若標準差大，應檢查是否有分組洩
漏、類別不平衡未分層，或樣本量不足。

#### 模擬題 SIM-L23303-003

模擬題 SIM-L23303-003 ｜ 程式判讀 ｜ 難度：整合 ｜ 對應 L23303
某工程師評估「同一批病患多次就診紀錄」（每位病患平均 4筆）的再住院風險模型。下列程式的主
要問題為何？
1X_res,y_res = SMOTE().fit_resample(X, y)
2scores= cross_val_score(model, X_res, y_res, cv=5)
3print(scores)
(A)沒有問題，合成過採樣可有效解決類別不平衡
(B)存在雙重洩漏：重採樣在交叉驗證外執行，使合成樣本同時進入訓練與驗證折；且同一病患的
多筆紀錄未依群體分折，會跨折出現
(C)應將cv=5改為cv=10即可解決
(D)cross_val_score會自動回傳平均分數，故print會印出單一數值
答案與逐項解析
答案：B
(A) ×重採樣本身沒錯，錯的是執行時機。在切分前合成，由訓練資料插值產生的合成點會出現在
驗證折中，模型等於看過驗證答案的近似版本。
(B)✓正解。兩個問題並存：其一，重採樣必須放進imblearn的管線，讓交叉驗證於每一折的訓練
部分內才執行；其二，同一病患的 4筆紀錄若分散於不同折，模型會在訓練時見過該病患、驗
證時又預測同一病患，屬群體洩漏，應改用 Group K-Fold並指定病患 ID為分組欄。
(C) ×增加折數不改變洩漏的本質，只會讓虛高的指標更穩定地虛高。
(D) ×回傳的是長度等於cv的陣列。
干擾項設計理由：(A)針對「用了正確技術就沒事」；(D)針對回傳型別的常見誤解。
延 伸 考 點： 正 確 寫 法 為 pipe = imblearn.pipeline.make_pipeline(SMOTE(), model)， 再 以
cross_val_score(pipe,X, y, cv=GroupKFold(5), groups=patient_id) 評估。須注意 sklearn 的
Pipeline不支援改變樣本數的步驟。

#### 模擬題 SIM-L23303-004

模擬題 SIM-L23303-004 ｜ 選型題 ｜ 難度：中級 ｜ 對應 L23303
某團隊建置「每日電力需求預測」模型，資料為三年份的日資料。下列交叉驗證方式何者最為適當？
(A) K-Fold，隨機分為 5折
(B) Stratified K-Fold，依需求量高低分層
(C) TimeSeriesSplit（前向鏈式），永遠以較早期間訓練、較晚期間驗證
(D)留一法，逐日驗證
答案與逐項解析
答案：C
(A) ×隨機分折會把未來日期放進訓練集、過去日期放進驗證集，等於用未來預測過去，指標必然
虛高且無法反映上線後表現。
(B) ×分層是針對分類任務的類別比例，本題為迴歸；且分層仍是隨機分折，同樣有時間洩漏。
(C)✓正解。時序資料必須維持時間順序：以第 1段訓練、第 2段驗證；再以第 1–2段訓練、第 3
段驗證，依此類推。這才能模擬真實的「以過去預測未來」情境。
(D) ×留一法計算量極大（三年約 1,095次訓練），且未解決時間順序問題。
干擾項設計理由：(B)混淆了「分層」（處理類別不平衡）與「時序」（處理時間依賴）兩種不同的需
求。
延伸考點：時序驗證還須設定間隔期——若特徵計算需回看 7天，訓練集結束與驗證集開始之間應留
7天空隙，避免驗證期的特徵使用到訓練期末的資料。四種切分方式的對應：一般資料 K-Fold／不
平衡分類 Stratified／分組資料 Group／時序資料 TimeSeriesSplit。

#### 模擬題 SIM-L23303-005

模擬題 SIM-L23303-005 ｜ 觀念題 ｜ 難度：中級 ｜ 對應 L23303
某醫療篩檢模型的漏檢（未檢出真正病患）後果嚴重，而誤報僅需增加一次複檢。若模型目前使用
預設閾值 0.5，下列調整何者最為適當？
(A)調高閾值至 0.8，以提高精確率
(B)調低閾值至 0.3，以提高召回率，並以複檢流程承接增加的誤報
(C)維持 0.5，因其為統計上的最佳值
(D)改以準確率作為唯一驗收指標
答案與逐項解析
答案：B
(A) ×方向相反。調高閾值會使預測為正者變少，漏檢增加——與「漏檢後果嚴重」的前提衝突。
(B)✓正解。漏檢代價高時應優先召回率，即調低閾值；代價是誤報增加，但題幹已說明誤報僅需
一次複檢，成本可承受。這是典型的成本導向閾值決策。
(C) × 0.5只是預設值，不是任何意義上的最佳值。最佳閾值取決於兩類錯誤的相對成本。
(D) ×篩檢情境通常類別極度不平衡，準確率會被多數類主宰而失去意義。
干擾項設計理由：(C)是實務上最常見的疏忽——很多團隊從未檢視過閾值。
延伸考點：最佳閾值可由期望成本求得：成本 =CFN ×FN +CFP ×FP，掃過所有閾值取最小者。
若 CFN是 CFP 的 100倍，最佳閾值會遠低於 0.5。此決策屬業務決策而非技術參數，應由業務單
位共同確認並文件化。

#### 模擬題 SIM-L23303-006

模擬題 SIM-L23303-006 ｜ 觀念題（反向） ｜ 難度：中級 ｜ 對應 L23303
關於模型評估指標，下列敘述何者錯誤？
(A) R2可能為負值，代表模型的預測比「一律猜訓練集平均值」還差
(B) RMSE對離群值比 MAE敏感，因其對誤差取平方
(C)極度不平衡的二元分類中，AUPRC通常比 AUROC更具鑑別力
(D) F1為精確率與召回率的算術平均，因此兩者之一極低時 F1仍可維持中等水準
答案與逐項解析
答案：D
(A)✓正確。R2的基準是「猜平均值」，比它差即為負。
(B)✓正確。
(C)✓正確。AUROC的偽陽性率分母含極大的 TN，變動不敏感而顯得樂觀。
(D) ×錯誤（即為答案）。F1是調和平均而非算術平均。調和平均會被較小值主導：若 P = 0.9、
R = 0.1，算術平均為 0.5，但 F1 = 2(0.9)(0.1)/1.0 = 0.18。這正是使用 F1的目的——懲罰兩者
失衡。
干擾項設計理由：(D)把正確的「兩者之一極低」情境接上錯誤的「仍可維持中等」結論，測試考生
是否理解調和平均的性質。
延伸考點：若業務上兩類錯誤的重要性不同，可用 Fβ：β > 1偏重召回率、β < 1偏重精確率。醫
療篩檢常用 F2。
