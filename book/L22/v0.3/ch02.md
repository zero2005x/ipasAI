### 2.1 核心概念與技術原理

<!-- pdf-page 22 -->
#### 2.1.1 六種常見分佈的辨識
核心必考
| 分布 | 描述的隨機現象 | 參數 | 典型場景 |
|---|---|---|---|
| 伯努利 | 單次二元試驗 | p | 單一客戶是否點擊 |
| 二項 | n 次獨立、成功率相同的試驗中的成功次數 | n、p | 固定次數投放中的轉換數 |
| 卜瓦松 | 固定區間內的事件次數 | λ | 每小時來電數、單片晶圓瑕疵點數 |
| 常態 | 對稱鐘形連續量 | µ、σ | 某些量測誤差或大樣本平均數的近似分布 |
| 指數 | 卜瓦松過程中的相鄰事件等待時間 | λ | 在相應假設下的來電間隔 |
| 均勻 | 指定區間內具有等密度的連續量 | a、b | 區間內均勻隨機取樣 |
卜瓦松與指數：一體兩面
若來電符合**到達率固定、互不重疊時間區間的增量獨立**之齊次卜瓦松過程（λ = 5次／小時），則「兩次來電之間的等待時間」服從指數分佈，平均間隔 1/λ = 0.2小時。單知某固定區間的總次數呈卜瓦松分佈，尚不足以推定間隔必為指數分佈。
題幹問「次數」用卜瓦松，問「時間間隔」用指數。
卜瓦松的另一特性：平均數等於變異數，皆為 λ。若實際資料的變異數遠大於平均數（過度離散），
可檢查事件群聚、速率變化等原因，並考慮負二項分佈等替代模型。

#### 2.1.2 常態分佈與 Z分數
核心必考
z = (x − µ) ÷ σ
經驗法則（68–95–99.7）：資料落在 µ±1σ、µ±2σ、µ±3σ的比例分別約為 68%、95%、99.7%。此
為製程管制（3σ界限）與異常偵測的基礎。
z = 2代表該值高於平均兩個標準差；標準常態分佈為 N(0,1)。

<!-- pdf-page 23 -->
#### 2.1.3 中央極限定理
核心必考
對獨立同分布、母體平均與變異數有限的樣本，n 足夠大時，樣本平均數的抽樣分佈近似常態，其標準差（標準誤）為 σ/√n。`n≥30` 只是常見經驗起點，不是普遍保證；母體高度偏態或重尾時可能需要更多樣本。
三個必考推論
1. 中央極限定理講的是樣本平均數的分佈，不是原始資料會變成常態。
2. 標準誤隨√n縮小——要把誤差減半需把樣本量變為四倍。
3. 這是許多以樣本平均數近似常態的信賴區間與檢定之理論基礎；另有精確分布與其他推論方法。

#### 2.1.4 考點補丁：PDF 與 CDF
核心必考

- **定義**：
  - **PDF（機率密度函數，Probability Density Function）**：連續隨機變數在某一點的密度，記為 f(x)。**PDF 的值不是機率**，可以大於 1。
  - **CDF（累積分布函數，Cumulative Distribution Function）**：F(x) = P(X ≤ x)，是**累積機率**，值域必在 [0, 1] 之間且單調不減。
- **兩者的關係**：
  - F(x) = ∫₋∞ˣ f(t) dt（CDF 是 PDF 的積分）。
  - f(x) = dF(x)/dx（PDF 是 CDF 的微分）。
  - P(a < X < b) = F(b) − F(a) = ∫ₐᵇ f(t) dt。
- **一句判斷規則**：題目給「小於某值的機率」→ 用 CDF；給「某區間的機率」→ CDF 相減；給「求密度」→ 對 CDF 微分。看到 f(x) > 1 **不要驚慌**，那是密度不是機率。
- **離散對照**：離散隨機變數用 **PMF（機率質量函數）**，P(X=x) 就是機率且必 ≤ 1；CDF 為階梯函數。連續隨機變數的 P(X=x) = 0。
- **易混點**：
  - **PDF 必須非負且全區間積分為 1**，但個別點的 f(x) 可任意大。例：均勻分布 U(0, 0.5) 的密度在 [0, 0.5] 上等於 2。
  - **CDF 一定單調不減**，且 F(−∞)=0、F(+∞)=1。
  - **常態分布的 CDF 沒有初等閉式解**，實務查標準常態表或用軟體 `norm.cdf`；考題通常給標準差倍數對應的機率（1σ≈68%、2σ≈95%、3σ≈99.7%）。
- **解題模板（常態分布）**：先把 X 標準化為 Z = (X − μ)/σ，再查 Z 的 CDF。求 P(X > a) = 1 − F_Z((a−μ)/σ)。

#### 2.1.5 考點補丁：二項分佈的常態近似
核心必考

- **定義**：n 次獨立伯努利試驗的成功次數 X ~ B(n, p)，平均數 np、變異數 np(1−p)。當 n 夠大時，X 近似 N(np, np(1−p))，這是中央極限定理用在「成功次數」上的結果。
- **一句判斷規則**：先算 **np 與 n(1−p) 是否都大於 5**（較保守的教材用 10）；兩者都達標才可用常態近似。只看 n 大不夠，p 極小或極大時一側的期望次數仍可能不足。
- **計算範例**：n = 400、p = 0.1 → np = 40、n(1−p) = 360，均大於 5，可近似為 N(40, 36)，標準差 6。
- **易混點**：
  - **不是只有 p = 0.5 才能近似**。p = 0.5 時分布對稱、近似最快，但其他 p 只要期望次數夠大也可以。
  - p 很小、n 很大、np 適中（例如罕見事件）時，較適合用**卜瓦松近似**（λ = np），而不是常態近似。
  - 以連續分佈近似離散分佈時，精確計算可加**連續性校正**：P(X ≤ k) ≈ P(Y ≤ k + 0.5)。
- **對應題號**：114-2 L22 Q31（正解 B）。

#### 2.1.6 考點補丁：scipy.stats 的 pmf／pdf／cdf／sf
核心必考

- **定義**：`scipy.stats` 的每個分佈物件都提供同一組方法：

  | 方法 | 意義 | 適用 |
  |---|---|---|
  | `pmf(k, ...)` | P(X = k)，恰好等於 k 的機率 | 離散分佈（二項、卜瓦松） |
  | `pdf(x, ...)` | 在 x 的機率**密度**（不是機率） | 連續分佈（常態、指數） |
  | `cdf(k, ...)` | P(X ≤ k)，小於**或等於** | 兩者皆可 |
  | `sf(k, ...)` | P(X > k) = 1 − cdf(k) | 兩者皆可 |

- **一句判斷規則**：程式出現 `pmf(5, λ)` 就是「**恰好 5 次**」的機率；「最多 5 次」要用 `cdf(5, λ)`；「超過 5 次」用 `sf(5, λ)`；「至少 5 次」是 `sf(4, λ)`（離散分佈要退一格）。
- **易混點**：
  - `poisson.pmf(k, mu)` 的 λ 是**平均發生次數**，不是上限；卜瓦松的 X 可以大於 λ。
  - 離散分佈「小於 5」是 P(X ≤ 4) = `cdf(4)`，不是 `cdf(5)`。
  - 對連續分佈呼叫 `pdf` 得到的是密度，可以大於 1（見 2.1.4）。
- **程式範例**：

  ```python
  from scipy.stats import poisson
  lam = 3
  poisson.pmf(2, lam)   # P(X = 2)
  poisson.cdf(2, lam)   # P(X <= 2)
  poisson.sf(2, lam)    # P(X > 2)
  ```

- **對應題號**：114-2 L22 Q42（正解 C，程式圖）。

### 2.2 常見陷阱與錯誤觀念
• 以為中央極限定理會讓原始資料變常態。它描述的是樣本平均數的抽樣分佈。
• 混淆卜瓦松與指數。問次數用卜瓦松，問間隔時間用指數。
• 把二項與卜瓦松混用。二項有明確的試驗次數 n；卜瓦松是在連續時間或空間上計次，沒有 n。
• 忽略獨立性假設。卜瓦松要求事件獨立發生；若來電有明顯尖峰群聚，模型即不適用。
• 誤以為標準誤等於標準差。標準誤是樣本平均數的標準差，為 σ/√n。

#### 模擬題 SIM-L22102-001

模擬題 SIM-L22102-001 ｜ 辨識題 ｜ 難度：基礎 ｜ 對應 L22102
某客服中心來電符合到達率固定、不同時間區間獨立的卜瓦松過程，平均每小時接到 6通。若欲建模「連續兩通來電之間的等待時間」，最適當的機率分
佈為何？
(A)二項分佈
(B)卜瓦松分佈
(C)指數分佈
(D)均勻分佈
答案與逐項解析
答案：C
(A) ×二項分佈描述固定次數試驗中的成功次數，本題無「固定試驗次數」。
(B) ×卜瓦松描述的是「每小時接到幾通」——即次數，不是間隔時間。
(C)✓正解。事件發生次數服從卜瓦松時，事件間隔時間服從指數分佈。本題平均間隔為 1/6小時
（10分鐘）。
(D) ×均勻分佈假設區間內等機率，與等待時間「短間隔較常見、長間隔較罕見」的實際型態不符。
延伸考點：若題幹改問「一小時內接到超過 10通的機率」，答案就變成卜瓦松。次數→卜瓦松、間
隔→指數是同一組現象的兩種問法。

#### 模擬題 SIM-L22102-002

模擬題 SIM-L22102-002 ｜ 計算題 ｜ 難度：中級 ｜ 對應 L22102
某產線零件重量近似常態分佈，µ = 50公克、σ = 2公克。若品管規定重量須落在 46至 54公克之
間，依經驗法則，約有多少比例的零件會被判定為不合格？
(A)約 0.3%
(B)約 5%
(C)約 32%
(D)約 68%
答案與逐項解析
答案：B
46 = 50−2×2，54 = 50+2×2，即 µ±2σ。
依經驗法則，µ±2σ內約含 95%資料，故落在區間外者約 100%−95% = 5%。
(A) × 0.3%對應 µ±3σ之外。
(B)✓正解。
(C) × 32%對應 µ±1σ之外。
(D) × 68%是 µ±1σ之內的比例，方向與問法相反。
干擾項設計理由：(D)直接取用經驗法則的數字但未依題目所問的「之外」轉換。
延伸考點：製程能力常以±3σ（約 99.7%）為管制界限，界外約 0.3%。若規格改為 µ±3σ，不合格
率降至約 0.3%——這也是六標準差管理的思路來源。

#### 模擬題 SIM-L22102-003

模擬題 SIM-L22102-003 ｜ 程式判讀 ｜ 難度：中級 ｜ 對應 L22102
執行下列程式後，關於m之分佈的敘述何者最為正確？

```python
import numpy as np
pop= np.random.exponential(scale=3, size=1000000)#母體：右偏
m= [np.mean(np.random.choice(pop, 100))for _ in range(5000)]
```

(A)m會呈現與母體相同的右偏分佈
(B)m的分佈近似常態，因為它是樣本平均數的抽樣分佈（中央極限定理）
(C)m的標準差會等於母體標準差
(D)m必為均勻分佈
答案與逐項解析
答案：B
(A) ×這是對中央極限定理最常見的誤解。母體雖為右偏的指數分佈，但m蒐集的是每次抽 100筆
的平均數，不是原始值。
(B)✓正解。樣本量 n = 100≥ 30，樣本平均數的抽樣分佈近似常態。
(C) ×m的標準差是標準誤，約為 σ/√100 =σ/10，遠小於母體標準差。
(D) ×無此結論。
干擾項設計理由：(A)針對「抽樣不會改變分佈形狀」的錯誤直覺；(C)針對標準誤與標準差的混淆。
延伸考點：若把100改為4，樣本量過小，中央極限定理的近似效果會明顯變差，m仍保有可見的右
偏。這正是「n≥ 30」經驗門檻的意義。
