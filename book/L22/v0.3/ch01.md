### 1.1 核心概念與技術原理

<!-- pdf-page 16 -->
#### 1.1.1 集中趨勢：三個統計量的選用
核心必考
| 統計量 | 定義 | 對離群值 | 適用 |
| --- | --- | --- | --- |
| 平均數 | 總和除以個數 | 敏感 | 數值資料；分布近對稱時較能代表中心 |
| 中位數 | 排序後居中之值 | 較穩健 | 偏態分布，如所得、房價、等待時間 |
| 眾數 | 出現次數最多之值 | 較穩健 | 類別型資料的常用代表值之一 |
:::key 偏態方向：必背的一句話
右偏（正偏態）：通常平均數 >中位數 >眾數。長尾拖向右側。典型例子為所得、理賠金額、網頁停留時間。

左偏（負偏態）：通常平均數 <中位數 <眾數。可能的例子是考生普遍高分、只有少數低分的考試成績；仍須以實際分布判定。

記憶法：平均數容易被長尾拖走。尾巴在哪邊，平均數通常就往哪邊偏（單峰分布的常見傾向，不是定理）。因此描述所得水準應報中位數，用平均數會被少數極高所得者拉高而失真。
:::
<!-- pdf-page 16 -->
#### 1.1.2 離散程度
核心必考
s² = Σ[i=1 至 n] (xᵢ − x̄)² ÷ (n−1)；s = √s²；CV = s ÷ x̄（x̄ 不為 0 時）。

符號：s² 為樣本變異數，分母 n−1 為貝索校正，使樣本變異數成為母體變異數的不偏估計；s 為樣本標準差，CV 為變異係數。
• 全距：最大減最小，極易受離群值影響。
• 四分位距 IQR =Q3−Q1，涵蓋中間 50%的資料，穩健。
• 變異係數 CV：無單位，可在平均數為正且遠離 0、資料有適當比例尺度時比較不同單位資料的相對變異。平均數接近 0 或可為負時不宜直接使用；比較股價與交易量的波動，也須先判斷此指標是否符合分析目的。

#### 1.1.3 箱型圖與離群值判定
核心必考
五數概括：最小值、Q1、中位數、Q3、最大值。鬚延伸至距箱體 1.5× IQR內的最遠資料點，超出者標為離群值。
下界 =Q1−1.5 IQR 上界 =Q3+1.5 IQR
例：Q1 = 20、Q3 = 40⇒ IQR = 20，界線為 20−30 =−10與 40+30 = 70。數值 75即為離群值。

此為本章高頻計算題。

#### 1.1.4 相關係數
核心必考
| 比較項 | Pearson 相關係數 | Spearman 等級相關係數 |
| --- | --- | --- |
| 衡量 | 線性關聯 | 單調關聯（以等級計算） |
| 資料要求 | 成對數值資料；計算係數本身不要求常態，常態假設影響部分推論方法 | 至少可排序的成對資料 |
| 對離群值 | 較敏感 | 通常較不敏感，但並非完全不受影響 |
| 值域 | [−1, 1] | [−1, 1] |

#### 1.1.5 考點補丁：從箱型圖形狀判讀分布
核心必考

- **定義**：箱型圖的「箱」是 Q1 到 Q3（長度＝IQR，中間 50% 資料的散布），箱內橫線是中位數，「鬚」延伸到 1.5×IQR 以內最遠的資料點，鬚外的點標為離群值。
- **一句判斷規則**：中位數線偏向箱子**下緣**（Q2−Q1 < Q3−Q2）且上鬚較長 → **右偏**；中位數線偏向**上緣**且下鬚較長 → **左偏**；中位數居中、兩鬚等長 → 大致對稱。
- **三種形狀的讀法**：

  | 看到的形狀 | 代表的意思 |
  |---|---|
  | 箱短、鬚長或有多個離群點 | 中段資料集中，但尾端有極端值 |
  | 箱長 | 中間 50% 資料分散（IQR 大），變異較大 |
  | 中位數靠箱子一側 | 分布偏態，偏向中位數的**反方向** |

- **易混點**：
  - **中位數靠下緣是右偏，不是左偏**。長尾在上方，平均數會被拉高到中位數之上。
  - 箱型圖**可以**判斷偏態方向，但看不出**多峰**；要看峰數須搭配直方圖或小提琴圖。
  - 箱子長短比較的是 IQR，不是全距；全距還要把鬚與離群點一起看。
- **對應題號**：115-1 L22 Q01（正解 A，含圖）。

#### 1.1.6 學習指引補充：峰度、幾何平均與調和平均
官方補充

- **峰度（kurtosis）**：描述分布尾部的厚薄。常態分布的峰度為 3（超額峰度為 0）。高峰度（超額峰度 > 0）代表尾部較厚、極端值較多；低峰度（< 0）代表尾部較薄。pandas 的 `kurt()` 回傳的是**超額峰度**。
- **幾何平均**：用於連乘關係，例如多期成長率的平均：平均成長率 = [(1+r₁)(1+r₂)⋯(1+rₙ)]^(1/n) − 1。例：兩年分別成長 +50% 與 −50%，算術平均是 0%，實際平均成長率是 √(1.5×0.5) − 1 ≈ −13.4%。
- **調和平均**：用於比率的平均，例如同樣距離往返的平均速度 = 2 ÷ (1/v₁ + 1/v₂)；F1 分數就是精確率與召回率的調和平均。
- **一句判斷規則**：成長率、報酬率連續複利 → 幾何平均；固定距離的平均速度、比率的平均 → 調和平均。
- **易混點**：對同一組正數，算術平均 ≥ 幾何平均 ≥ 調和平均；箱型圖的鬚延伸到 1.5×IQR 以內最遠的資料點，不一定到最大、最小值（見 1.1.3）。
- **指引頁碼**：學習指引科目二 3-2、3-4、3-9～3-12。

### 1.2 程式判讀重點
核心必考

#### 1.2.1 pandas 摘要統計的回傳型別與缺值

```python
df.describe()#->DataFrame（有數值欄時預設統計數值欄）
df['sales'].describe()#->Series
df.mean(numeric_only=True)#->Series（數值欄的平均，預設略過 NaN）
df['sales'].mean()#->純量
df.median(numeric_only=True)
```

`DataFrame.describe()` 有數值欄時預設只摘要數值欄；若全是非數值欄，會改列次數等摘要。因此不能把「只回傳數值欄」當成無條件規則。含文字欄的資料表若要算各數值欄平均，可明確指定 `numeric_only=True`。

三個必考細節：(1)數值欄 `describe()` 的 50% 就是中位數；(2)數值聚合函式通常預設略過 NaN，因此 `df['x'].sum()/len(df)` 與 `df['x'].mean()` 在有缺值時可能不相等；(3) pandas `std()` 預設 `ddof=1`（樣本標準差），NumPy `std()` 預設 `ddof=0`（母體標準差），一般資料的結果不同，但常數資料可同為 0。

判讀 `describe()` 輸出的四個要點：
- `count` 是**非缺失**筆數；某欄 `count` 比其他欄少，差額就是該欄的缺值數。資料列數要看最大的 `count` 或 `len(df)`，不是某一欄的 `count`。
- `mean` 是平均數，`50%` 才是中位數；兩者差距大表示分布偏態。
- `25%`、`75%` 分別是第一、第三四分位數（Q1、Q3），IQR = Q3 − Q1。
- 欄數要數表頭的欄位；`describe()` 預設只列數值欄，文字欄不會出現。

### 1.3 常見陷阱與錯誤觀念
• 相關不等於因果。冰淇淋銷量與溺水人數高度相關，共同原因是氣溫（干擾變數）。
• Pearson = 0不等於獨立。若 y = x² 且 x對稱分布於 0兩側，Pearson可為 0，但兩者完全相依。務必搭配散布圖檢視。
• 辛普森悖論。分組後每組趨勢與合併後趨勢相反，在比較分行或科別績效時極常見。
• 標準差為 0代表該欄為常數，對模型毫無資訊量，應於前處理刪除。
• 以平均數描述偏態資料。所得、房價等右偏資料宜報中位數，或平均數與中位數並列。
• 混淆母體與樣本標準差。pandas預設`ddof=1`，numpy預設`ddof=0`。

#### 模擬題 SIM-L22101-001

模擬題 SIM-L22101-001 ｜ 計算題 ｜ 難度：基礎 ｜ 對應 L22101
某組資料之 Q1 = 32、Q3 = 68。依 1.5× IQR準則判定，下列哪一個數值屬於離群值？
(A)−20
(B) 12
(C) 100
(D) 125
答案與逐項解析
答案：D
IQR = 68−32 = 36，1.5×36 = 54。

下界 = 32−54 =−22；上界 = 68+54 = 122。
(A) ×−20大於下界−22，落在界內，不是離群值。
(B) × 12落在 [−22,122]內。
(C) × 100落在界內。
(D)✓正解。125超過上界 122，為離群值。
干擾項設計理由：(A)利用「負值看起來就很異常」的直覺，實際上−20仍在下界之內；(C)設在接近上界處，測試是否確實計算而非目測。
延伸考點：1.5× IQR為溫和離群值準則，3× IQR為極端離群值準則。若改以 3倍計算，上界為68+108 = 176，則 125不再是離群值——命題若指定倍數，務必依題目所給者計算。

#### 模擬題 SIM-L22101-002

模擬題 SIM-L22101-002 ｜ 觀念題 ｜ 難度：基礎 ｜ 對應 L22101
某縣市家戶年所得資料呈明顯右偏（少數極高所得者）。若欲向大眾說明「一般家庭的所得水準」，下列何者最為適當？
(A)使用平均數，因其利用了全部資料的資訊
(B)使用中位數，因平均數會被少數極高所得者拉高而失真
(C)使用全距，因其能呈現所得的完整範圍
(D)使用眾數，因其代表最多人擁有的所得
答案與逐項解析
答案：B
(A) ×「利用全部資料」正是問題所在——右偏分布中，少數極端值會把平均數拉離多數人的實際水準。
(B)✓正解。右偏時平均數 >中位數 >眾數；中位數對離群值穩健，最能代表「一般」家庭。
(C) ×全距描述的是離散程度而非集中趨勢，且受兩個極端值完全支配。
(D) ×連續型所得資料的眾數不穩定（需先分箱），且會低估整體水準。
延伸考點：官方統計常同時公布平均數與中位數，兩者差距本身即為所得分配不均的訊號——差距越大代表右偏越嚴重。

#### 模擬題 SIM-L22101-003

模擬題 SIM-L22101-003 ｜ 程式判讀 ｜ 難度：中級 ｜ 對應 L22101
給定 df 有欄位 sales，總列數為 100，其中 3 筆為 NaN，其餘 97 筆皆為正值。執行下列程式後，a 與 b 的關係為何？

```python
a= df['sales'].mean()
b= df['sales'].sum()/len(df)
```

(A)a== b，因兩者皆為平均數
(B)a> b，因`mean()`略過 NaN（分母為 97），而b的分母為 100
(C)a < b
(D)兩者皆會因 NaN而回傳 NaN
答案與逐項解析
答案：B
(A) ×分母不同。
(B)✓正解。`mean()`與`sum()`皆預設略過 NaN，故分子相同；但`mean()`的分母是非缺失筆數 97，而len(df)是總列數 100。分子相同、分母較大者較小，故 a>b（假設 sales均為正值）。
(C) ×方向相反。
(D) ×pandas聚合函式預設skipna=True，不會回傳 NaN。這與numpy.`mean()`不同——後者遇 NaN會回傳 NaN，須改用numpy.`nanmean()`。
干擾項設計理由：(D)針對pandas與numpy對 NaN處理差異的混淆。
延伸考點：若 sales含負值，a > b的結論不必然成立——嚴格說法是「分母不同故通常不相等」。實務上要計算「含缺值視為 0的平均」應寫`df['sales'].fillna`(0).`mean()`，語意才明確。

#### 模擬題 SIM-L22101-004

模擬題 SIM-L22101-004 ｜ 程式判讀 ｜ 難度：中級 ｜ 對應 L22101
假設 df['x'] 至少有兩筆非缺失、彼此不全相同的數值，且沒有 NaN。關於下列程式之敘述，何者錯誤？

```python
s1= df['x'].std()
s2= np.std(df['x'].values)
d= df.describe()
```

(A)s1為樣本標準差（`ddof=1`），s2為母體標準差（`ddof=0`），兩者數值不同
(B)d為 DataFrame，其50%一列即為中位數
(C)d預設僅摘要數值型欄位
(D)s1與s2必定相等，因為兩者計算的都是同一欄的標準差
答案與逐項解析
答案：D
(A)✓正確。pandas的`std()`預設`ddof=1`（分母 n−1）；numpy.`std()`預設`ddof=0`（分母 n）。
(B)✓正確。
(C)✓正確。若要納入類別欄需傳include='all'。
(D) ×錯誤（即為答案）。在題設非零變異條件下，兩者分母不同，故樣本標準差略大於母體標準差。若所有數值相同，兩者都為 0，不能說必然不同。
延伸考點：貝索校正（n−1）的目的是讓樣本變異數成為母體變異數的不偏估計。當 n很大時兩者差異可忽略，但在小樣本（如 n = 10）差異明顯。此考點在 L23101會以ddof參數形式再次出現。

#### 模擬題 SIM-L22101-005

模擬題 SIM-L22101-005 ｜ 程式判讀 ｜ 難度：中級 ｜ 對應 L22101
在 pandas 2.0+ 環境下，某資料表 `df` 同時包含數值欄位（如 `age`、`income`）與字串型類別欄位（如 `name`、`city`）。若資料分析師直接呼叫 `df.mean()` 而未傳入額外參數，下列敘述何者最為正確？
(A)pandas 會自動將字串欄位轉為字元長度後計算全域平均
(B)pandas 2.0+ 預設 `numeric_only=False`，因無法對文字欄位進行數值聚合，直接執行會拋出 `TypeError`；若僅欲計算數值欄位平均，應顯式傳入 `df.mean(numeric_only=True)`
(C)pandas 會自動刪除所有字串欄位並覆寫原始檔案
(D)無論資料型別為何，pandas 均無條件保證回傳 Series 且不拋出任何例外
答案與逐項解析
答案：B
(A) ×pandas 聚合運算不會自動將文字轉為字元長度。
(B)✓正解。在 pandas 2.0 以前的舊版本，`numeric_only` 預設為 `None` 或靜默忽略字串欄位；但自 pandas 2.0 起，此參數預設為 `False`，遇到非數值欄位無法計算時會直接拋出 `TypeError`。工程實務上若需對混合型態 DataFrame 進行聚合，必須明確指定 `df.mean(numeric_only=True)`。
(C) ×呼叫 `mean()` 屬於查詢聚合動作，不會刪除或覆寫原始 DataFrame 之欄位。
(D) ×忽略版本 API 變更即容易在生產環境引發非預期例外。
干擾項設計理由：(D)為沿用舊版 pandas 習慣開發者最常見的實務盲點。
延伸考點：類似的參數變更亦出現在 `df.median(numeric_only=True)` 與 `df.std(numeric_only=True)`，撰寫強健管線時皆建議明確給定 `numeric_only=True`。

#### 模擬題 SIM-L22101-006

模擬題 SIM-L22101-006 ｜ 計算題 ｜ 難度：基礎 ｜ 對應 L22101
某電商平台分析 1,000 位會員年度消費金額，經摘要統計得第一四分位數 $Q_1 = 40,000$ 元、第三四分位數 $Q_3 = 70,000$ 元。若依據 Tukey 盒狀圖（Boxplot）常用之四分位距準則判定異常值，消費金額高於多少元以上會被標記為「高位離群值（Outlier）」？
(A) 70,000 元
(B) 85,000 元
(C) 115,000 元
(D) 145,000 元
答案與逐項解析
答案：C
四分位距 $IQR = Q_3 - Q_1 = 70,000 - 40,000 = 30,000$ 元。

高位離群門檻（Upper Fence）公式為：$Q_3 + 1.5 \times IQR$。

計算：$70,000 + 1.5 \times 30,000 = 70,000 + 45,000 = 115,000$ 元。

故消費金額高於 115,000 元者被標記為高位離群值。
(A) × 70,000 元僅為第三四分位數（前 25% 門檻），不是離群值邊界。
(B) × 誤以 $Q_3 + 0.5 \times IQR = 70,000 + 15,000 = 85,000$ 計算。
(C)✓正解。
(D) × 誤以 $Q_3 + 2.5 \times IQR$ 計算。
干擾項設計理由：(A)混淆分位數與異常邊界；(B)(D)測試考生是否熟記標準乘數 1.5。
延伸考點：低位離群門檻（Lower Fence）公式為 $Q_1 - 1.5 \times IQR$；本例中 $40,000 - 45,000 = -5,000$ 元，因消費金額不為負值，故本資料無低位離群值。若將乘數 1.5 改為 3.0，則為「極端離群值（Extreme Outlier）」門檻（本例為 160,000 元）。
